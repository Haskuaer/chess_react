# React Chessboard

A small frontend experiment focused on building a chessboard interface using React, Tailwind CSS, and CSS Modules.

## About

This project was originally intended to be part of my React Playground, but was eventually developed as a separate repository.

The main goal was to practice building reusable components, organizing styles, and creating a chess game.

## Technologies

- React
- Tailwind CSS
- CSS Modules

## Features

- Chessboard layout
- Component-based structure
- Styling with Tailwind CSS and CSS Modules

## Status

**Incomplete / Learning Project** - The project currently focuses on the chessboard interface. Full chess game functionality has not been implemented, and further development is not currently planned.
